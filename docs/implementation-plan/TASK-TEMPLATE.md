# Шаблон атомарной задачи

## D-NNN — Короткий результат

- **Зависит от:** ID задач или gate.
- **Спецификация:** точные файлы и разделы.
- **Результат:** одно проверяемое изменение.
- **В scope:** 2–5 конкретных пунктов.
- **Не в scope:** соседние функции, которые легко случайно захватить.
- **Тесты:** unit/integration/fixture/failpoint и важные случаи.
- **Приёмка:** наблюдаемый результат и команды проверки.
- **Evidence:** заполняется после выполнения в `PROGRESS.md`.

Если описание требует двух независимых результатов или тестовый прогон нельзя осмысленно
интерпретировать без второй половины, задачу надо разделить.
